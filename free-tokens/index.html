data.json 没有加载成功

页面内容是数据驱动的，所有入口都从 data.json 读取。直接用 file:// 双击打开时，浏览器会因为安全策略拒绝读取本地 JSON。

两种解决办法，任选其一：

  1. 双击项目根目录的 start.bat，它会起一个本地服务并自动打开浏览器。
  2. 用 VS Code 装 Live Server 插件，右键 index.html → Open with Live Server。
